# Motorcycle china300 2t Carburator jets wizard

Конфигуратор жиклеров карбюратора для китайских мотоцилов с копией двигателя KTM EXC 300
- Hengjian Z300 (Хенжан, Камакс, Лекстра, ГР8)
- Koshine 320 (Кошайн)
- Miura
- AJ1
- Nibbi

 На основе выгрузки из чата [China 300 2T](https://t.me/china300_2T) за 2024-25 годы и опыта чатлан сделал интерактивный файл по выбору жиклера под мот/карб. 

 Файл носит чисто информативный характер, все действия вы делаете на свой страх и риск☝️ Все китайские двигатели/карбы/жиклеры разные‼️
